# IndieGoodies Homebrew Tap

Homebrew casks for [IndieGoodies](https://indiegoodies.com) apps.

## Install

```sh
brew install indiegoodies/tap/<app>
```

Or tap first, then install:

```sh
brew tap indiegoodies/tap
brew install --cask <app>
```

## Apps

### PastePal

Universal clipboard manager for Mac, iPhone, and iPad.

```sh
brew install indiegoodies/tap/pastepal
```

[indiegoodies.com/pastepal](https://indiegoodies.com/pastepal)

### Overcal

Menu bar calendar with agenda, world clocks and meeting reminders.

```sh
brew install indiegoodies/tap/overcal
```

[indiegoodies.com/overcal](https://indiegoodies.com/overcal)

### Typefu

Text expander with fill-in snippets, selected text actions and on-device AI.

```sh
brew install indiegoodies/tap/typefu
```

[indiegoodies.com/typefu](https://indiegoodies.com/typefu)

### Dojo

Developer tools for formatting, converting, encoding and generating. Apple Silicon only.

```sh
brew install indiegoodies/tap/dojo
```

[github.com/IndieGoodies/Dojo](https://github.com/IndieGoodies/Dojo)

### Cleana

Cleaner for developer caches, build output, simulators and app leftovers.

```sh
brew install indiegoodies/tap/cleana
```

[indiegoodies.com/cleana](https://indiegoodies.com/cleana)

### Coolbar

Menu bar bookmarks for files, links, text and images.

```sh
brew install indiegoodies/tap/coolbar
```

[indiegoodies.com/coolbar](https://indiegoodies.com/coolbar)

### Turbo

Keyboard-first launcher with clipboard history, snippets, AI and extensions.

```sh
brew install indiegoodies/tap/turbo
```

[indiegoodies.com/turbo](https://indiegoodies.com/turbo)
